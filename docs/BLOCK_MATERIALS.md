# Block materials

`torchlight_bp/block_materials.json` uses the shared native Torchflower profile: mining 0, blast 0,
catch_chance_modifier 30, destroy_chance_modifier 100, any-tool collection. Format 1.21.120; the omitted
lava_flammable keeps the default of no adjacent-lava ignition.

Source: Bedrock one-block-flower row of the Fire spread table (Nov 2025 archive). Not observed in game; flowing
lava still needs a native comparison. Standard: `.claude/skills/bedrock-blocks/references/materials.md`.
